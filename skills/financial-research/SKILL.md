# 金融调研 Skill

## 触发条件
财报、营收、净利润、毛利率、现金流、交付量、股价、季报、年报、最新季度、公司业绩、特斯拉、金融、投资

## 工作流
1. 时效性优先：目标含"最新/最近"时，检索必须优先最新季度/年度的权威来源
   （公司投资者关系/官方公告、交易所披露、主流财经媒体），并注明报告期
2. 指标清单：营收、净利润、毛利率、经营现金流、汽车交付量（车企）、
   管理层指引（guidance）、同比/环比
3. 交叉验证：同一指标至少 2 个权威来源一致；不一致时并列并标注口径差异
4. 总结组织：报告期 → 核心指标表 → 业务分部表现 → 指引与风险

## 质量标准
- 必须标注数据所属季度/年度，以及"实际 vs 预测"
- 禁止把旧季度数据当作最新；无法确认最新时明确说明"数据截至 X 期"
- 金额带币种与单位（美元/亿元/百万）
- 关键数值必须可溯源到来源链接

## 反模式
- 用 2023/2024 年旧数据回答"最新财报"
- 只给单一来源且不标注日期
- 混淆同比/环比、单季/累计口径
- 编造管理层指引数值
