# 调研报告 Skill

## 触发条件
- 目标包含：调研、研报、分析报告、市场、趋势、可视化、行业现状

## 工作流
1. 检索：一次 web_search 收集与主题直接相关的权威来源（官方/机构/主流媒体），保留原始 URL
2. 总结：content_summary 输出 总体摘要/关键发现/数据要点（表格：机构|指标|数值|年份|口径|来源）/建议
3. 图表：仅当存在 ≥2 个可对比数据点且有明确结论时生成图表（遵守图表 5 类规范）
4. 报告：report_generator 输出可交付 Markdown（概述/正文/关键数据一览/数据来源附录）

## 质量标准
- 每个关键数值必须带来源、时间、地域、单位；不同口径分开标注，禁止混用
- 主题纪律：只输出与目标直接相关的内容，离题数据（如无关领域的数值）一律剔除
- 图表：柱状从 0 起、类别降序、色盲友好、标注完整（标题含指标+时间+单位+来源）

## 反模式
- 把单数据点画成图（无结论不画图）
- 编造数值或四舍五入改变量级（1059.8 不能写成 1060）
- 报告只有摘要没有正文（正文必须覆盖目标全部要求）
