# 新人上手指南（Windows）

日期：2026-09-26　对应运行包版本：`2026.09.26.4`

给"只想把织光跑起来、不想先学 Python/Node/Docker"的人。**主路径只有一步：双击 `start.bat`。**

## 1. 三十秒版

1. 解压 `weavemind-<版本>-win-x64.zip`（目录里有中文或空格都没关系）。
2. 双击 `start.bat`。首次启动会自动准备 Redis、检查依赖、拉起服务，然后打开浏览器。
3. 在浏览器里按「首次使用引导」填模型服务与密钥，然后提交你的第一个研究任务。
4. 停止：双击 `stop.bat`。

不需要：系统 Python、Node.js、Docker、手工 `pip`、编辑 JSON、选 pip 镜像。

## 2. 我该走哪条路

| 你是 | 用哪个 | 需要什么 |
|---|---|---|
| 只想用起来（默认） | 运行包：解压后双击 `start.bat` | Windows x64 + 浏览器 |
| 要改代码 / 跑测试 | 源码：`git clone` 后双击 `start.bat` | Python 3.10–3.14；Redis 6+（可自动获取便携版） |
| 要容器化部署 | `docker compose up -d` | Docker；见 [部署指南](部署指南.md) |

源码方式、Docker、高级配置都保留，但**不是新人的前置知识**。

## 3. 首次启动你会看到什么

`start.bat` 打印的每一步都对应一个真实检查，失败时只给一个下一步：

| 输出行 | 含义 | 你要做什么 |
|---|---|---|
| `[1/6] Python` + `Source: packaged runtime (...)` | 用的是**包内**解释器（不是系统的） | 无 |
| `依赖：已检查并补齐缺失项` | 依赖与便携 Redis 就绪（包内已附 Redis 压缩包，离线可用） | 无 |
| `配置：模型/密钥待填写` | 工作台已起来，但还没配模型 | 到浏览器里完成「首次使用引导」 |
| `启动校验：16/16 服务存活` | 服务进程都活着 | 无（进程数**不等于**可研究） |
| `工作台：HTTP 200 @ 8080` | 浏览器地址可用 | 打开 `http://localhost:8080` |
| `研究能力：就绪（Redis 8、编排器与 5 项必需 Worker 心跳新鲜）` | 可以提交真实研究任务 | 无 |
| `研究能力：未就绪——…` | 缺 Redis / 心跳过期 / 编排器未存活 | 按提示看 `logs\` 后重试；**此时不要提交研究任务** |
| `代码执行：容器隔离不可用` | 只有"生成并运行代码"的步骤会被拒绝 | 公司研究不需要它；**不要**用关闭隔离来解决 |

无密钥也能先用：页面里的「查看内置演示」会一直标注"内置演示，不是本次实时生成"，
不写入任何研究统计。真实研究必须用你自己的模型配置。

## 4. 出问题时的对照表

| 症状 | 原因 | 下一步（只有一个） |
|---|---|---|
| `ERROR: no usable Python 3.10+ found` | 没有系统 Python，且包内 `runtime\python.exe` 缺失或损坏 | 重新解压运行包（包内自带运行时，正常不会走到这里） |
| 控制台停在"正在获取便携版 Redis"很久，最后失败 | 包内 `\.weavimind\downloads\redis-windows.zip` 被删过，且当前无网络 | 恢复该压缩包（或联网后重跑）；也可以自行安装 Memurai / redis-windows（Redis 6+）后重跑 |
| `端口 8080 已被其它程序占用，本实例改用 8081` | 别的软件占着 8080 | 无：按控制台/`launcher.py url` 给出的地址打开即可 |
| 页面报"鉴权失败（key 可能无效或已过期）" | 密钥错/过期/额度不足 | 在原页面改正密钥后重试；不要反复自动重试 |
| 防火墙弹窗询问 `redis-server.exe` | 便携 Redis 只监听回环 | 允许或取消都不影响本机使用（不会暴露局域网） |
| 有代理的环境（企业网） | `HTTP_PROXY` 会接管本机请求 | 已处理：回环健康检查不走代理，并把回环加入 `NO_PROXY` |
| 想给别的机器复制一份 | 运行包可整体移动 | 整个目录拷走即可；`.weavemind\` 是本实例状态，可一起带或删掉重建 |
| 同机已经有另一个织光实例在跑 | 端口会冲突 | 后启动的实例自动让位到空闲端口（控制台与页面都写明实际地址），且不会停掉先启动那个；两个实例若指向同一个 Redis 会共用消息总线，建议只留一个在跑 |

出问题的通用动作：看包内 `logs\`，或执行
`runtime\python.exe launcher.py diagnostics diag.txt` 生成**脱敏**诊断（不含密钥、不会自动上传）。
