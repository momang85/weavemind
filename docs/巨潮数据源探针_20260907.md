# 巨潮资讯网数据源探针结论（2026-09-07）

## 背景

市场导向改进 T1c：计划把 A 股财报数据源从东方财富（第三方聚合）升级为巨潮资讯网（深交所指定法定信息披露平台），作为"数据源官方化"合规叙事的落点。

## 探针过程与结论

对 `www.cninfo.com.cn` 的公开接口做了 5 轮探测（详见 git 历史本轮探针命令）：

| 接口 | 结果 |
|---|---|
| POST `/new/hisAnnouncement/query`（公告搜索，category_ndbg_szsh 年报） | HTTP 200 JSON 可达，但 `announcements` 恒为空——`stock` 参数格式（`300750` / `code,orgId` / `gssz0300750`）、`seDate` 窗口、`Referer`/`X-Requested-With` 伪装均无数据 |
| 同上 + 沪市 `sse` 栏目（600519） | 请求超时 |
| GET `/new/data/szse_stock.json`（orgId 映射表） | 超时 |
| GET `/new/information/topSearch/detailOfQuery`（orgId 查询） | HTTP 500 |
| `webapi.cninfo.com.cn/new/hisAnnouncement/query`（webapi 镜像） | HTTP 405（webapi 财务数据族疑似 mcode token 门禁） |

**结论**：无浏览器 cookie/无 token 的服务端请求拿不到巨潮数据。公告搜索接口对非浏览器流量返回空集，webapi 财务接口直接拒绝。这不是参数问题——是访问门槛。

## 决策（按计划预案收口）

1. **`adapters/cninfo.py` 以骨架 + 环境开关形态入库**：`WEAVEMIND_CNINFO_ENABLED=1` 启用（默认关闭）。输出契约与 `eastmoney.fetch_ashare` 完全一致（含 `rd_expense`，亿元）。
2. **路由层接入 `fetch_cn_or_fallback`**：巨潮优先（启用且可用时），东财 `fetch_ashare` 兜底；默认关闭时行为与现状完全一致。
3. **本轮的实际收益来自同批的另外两项**：路由误判修复（"市场份额"类措辞的公司对比目标此前被误路由到全市场排行，今天 18 分钟任务拿不到财务数据的真正根因）+ 研发投入字段全链路（`RDEXPEND` 键已实证，年报行 2025 年宁德时代研发投入 221.47 亿元）。
4. **后续接通巨潮的两条路径**（需要时再做）：
   - 官方数据服务授权（webapi token）——合规叙事最完整；
   - 年报 PDF 科目解析（公告 adjunctUrl 是 PDF，需要新增 PDF 财务表解析器）。

## 复现

```python
# 公告搜索恒空的最小复现（2026-09-07 实测）：
import urllib.request, urllib.parse, json
url = "http://www.cninfo.com.cn/new/hisAnnouncement/query"
data = urllib.parse.urlencode({
    "pageNum": "1", "pageSize": "5", "column": "szse", "tabName": "fulltext",
    "stock": "300750,gssz0300750", "category": "category_ndbg_szsh",
    "seDate": "2024-01-01~2026-12-31", "isHLtitle": "true",
}).encode()
req = urllib.request.Request(url, data=data, headers={
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64)",
    "Content-Type": "application/x-www-form-urlencoded; charset=UTF-8",
    "Referer": "http://www.cninfo.com.cn/new/commonUrl/pageOfSearch?url=disclosure/list/search",
    "X-Requested-With": "XMLHttpRequest",
})
print(json.loads(urllib.request.urlopen(req, timeout=15).read()))
# => {"announcements": null 或 [], "totalAnnouncement": 0, ...}
```
