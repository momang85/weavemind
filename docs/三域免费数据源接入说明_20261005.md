## 三、免费源的能力与许可边界（下单/使用前必读）

| 源 | 免费版能给什么 | 许可与限制 |
|---|---|---|
| **akshare** | A 股日线（可前复权）、指数日线、交易日历等公开接口 | **无正式许可** → 标 `免费源·仅内部试验`；接口随上游网页变化，**稳定性无保障**；不得进对外包 |
| **tushare 免费档** | 120 积分：**仅非复权日线** | 个人非商业、个人查看；要复权/分钟/实时须购买档位（见采购决策单） |
| **Kaggle 数据集** | 需 `kaggle.json` API token 或网页下载 | **逐个数据集看 license**；金融类多为抓取/衍生数据，权利不清 → 只作内部试验，记录 `license=unknown` 与来源 URL |
| **天池（阿里）数据集** | 需登录/参赛协议，无匿名 API | 仅按数据集页面的使用条款；**我不能代登录**——你下载后给我文件，我按同一契约导入并记录许可 |

**统一规则**：`license` 随数据落盘（`source/license/imported_at/可用范围`），`unknown` 按"仅内部试验"处理并显式标注；
对外交付只交付**衍生结论**，或先取得机构授权。
