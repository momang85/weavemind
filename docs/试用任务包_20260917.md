# 试用任务包（2026-09-17，S3）

给**非开发者**的一次完整试用：从安装到导出，全程在浏览器里完成；不需要写代码、不需要
命令行（除了第一次启动）。目标不是"跑一个任务"，而是验证一件事：

> **你能否从一份公司研究稿点到来源、复算关键数字、修订并导出**——并且少花资料整理与数字返工。

## 一、准备（约 10 分钟）

1. 装 **Python 3.10+**（Windows 上 `python --version` 能看到版本即可）。
2. 拿到仓库：`git clone <仓库地址>` 或解压压缩包，进入目录。
3. 准备一个 **OpenAI 兼容的模型 API Key**（余额要够跑 2–3 个任务）。
4. 启动：Windows 双击 `start.bat`（或命令行 `python launcher.py`）。
   - 首次启动会自动装依赖、必要时获取便携 Redis；看到 `N/N 服务存活` 即成功。
   - 首次会进入中文引导：选供应商 → 填 Key → 选模型 → 可当场测连通性。
5. 浏览器打开 **http://localhost:8080**，用你的账号登录（首次会让你创建管理员）。

**出问题怎么办**：`python launcher.py status` 看服务状态；`python launcher.py deps` 看依赖；
日志在 `logs/`。

## 二、研究一家公司（首发路径）

1. 在首页「研究一家公司」表单里填：
   - **公司**：名字或代码（如 `贵州茅台` 或 `600519.SH`）；
   - **两个年度**（如 2023 / 2024）——首发路径按两期做同比；
   - **报表口径**：合并 / 母公司（不确定就问你的财务同事，**不要留空猜**）；
   - **资料截至日**（如 2025-04-30，报告会明示数据时效）。
2. 点「生成研究目标（写入输入框）」——它会拼出一段明确的目标写进输入框，**你可以继续手改**。
   - 表单缺项时它**不会**替你猜，而是列出缺什么。
3. 点提交，等运行结束。可选勾「先确认计划」以便执行前编辑步骤。

## 三、看结果（顺序就是验收顺序）

1. **结论与目标达成**：页面顶部先给"可重算底稿"面板——目标**达成/未达成**、
   六个必需组合（3 指标 × 2 年度）齐备情况。
2. **缺口与待核验项**：缺少的事实、主体冲突、币种不明、累计/单季混用都会列出来。
   **有缺口的报告不得当成已完成**。
3. **关键指标**：每条带 `fact_id`、主体、期间、币种单位、**来源链接**、核实状态。
4. **计算值**：同比等派生值单独列出，附**公式与输入 fact_id**——你可以自己算一遍。
5. **导出**：报告 Markdown / PDF，以及**底稿** `working_paper.csv`（明细 / 派生 / 缺口三段）。

## 四、复算（这一步是本次试用的重点）

挑 1–2 个关键数字：

1. 在底稿表里找到那一行，点「来源位置」去看原始来源；
2. 自己按公式把同比算一遍，和页面上的数对一下；
3. 若对不上或来源打不开，**记下来**——这正是我们要的信号（不是你的操作问题）。

## 五、修订与重验

1. 在结果页做修订（目前通过 `POST /api/task/<id>/review/edit`，界面入口随 S2 后续补齐）。
2. 修订会生成**新版本**：旧验收与旧批准**不会**自动迁移，必须重新验证通过——
   页面上会如实显示"未验收草稿"。

## 六、请记下这 6 个指标（本次试用的产出）

| 指标 | 怎么记 | 记不了就写"未知" |
|---|---|---|
| 首次拿到可复核报告耗时 | 从点提交到看到底稿面板的分钟数 | 别写 0 |
| 必需指标覆盖 | 底稿面板显示的 `x/6` | 别写 0 |
| 错误认证数 | 你复算后发现的"看着可溯源其实不对"的条数 | 没复核就别填 |
| 人工修改的关键字段数 | 你改了底稿/报告里几个数 | 没改可写 0（这是真的 0） |
| 复核耗时 | 从开始复核到确认/放弃的分钟数 | 别写 0 |
| 费用 | 已知就填金额；只能估就标"估算"；不知道就留"未知" | 未知不等于 0 |

采集（可选，命令行一条）：

```
python scripts/trial_record.py add --task-id <任务ID> --category trial ^
    --edited-fields 2 --review-seconds 300 --cost-usd 0.35 --cost-kind known --would-again yes
python scripts/trial_record.py summary
```

> 记录里**不含**姓名/邮箱等身份信息，只有匿名试用号与任务 id；未知项单列，不并入中位数与总额。

## 七、这次试用的边界（先知道，免得误会）

- 首发路径默认 **A 股公开年报**（东财结构化财务）；**港股/美股**保留适配但**未在真实数据上验证**。
- 美股真实 SEC 抓取**未跑通**（依赖境外网络）。
- 底稿里的报表口径可能显示 `unknown`（适配器未声明）——那是如实标注，不是 bug。
- 报告质量取决于你选的模型；**结构化链路命中时数字可复算，未命中时会大量标"数据缺失"**。
