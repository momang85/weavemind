输入一句目标，一支 AI 团队并行干活

👀 看得见

实时任务树、Agent 拓扑、每一步的结果——不再是黑箱。

🧠 会记忆

ChromaDB 长期记忆，同类任务自动复用成功经验。

🧬 会进化

策略变异 → 锦标赛 → 安全红线 → 人工审批部署。

✏️ 听指挥

计划可编辑、确认后执行；同一会话可连续追问。

🔁 会自我完善

任务后自动验收评审，不达标就追加步骤继续迭代。

🧑‍💼 开箱即用

Windows / macOS / Linux / Docker 一键启动。

30 秒快速体验

git clone https://github.com/momang85/weavemind.git && cd weavemind
cp config.example.json config.json   # 填入你的 LLM API Key
bash start.sh                        # 或 start.bat / docker compose up --build -d
