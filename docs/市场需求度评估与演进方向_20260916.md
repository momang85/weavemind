## 一、结论摘要

1. **"AI 辅助投研"这个方向的需求是真实的，且刚被三路互相独立的证据印证**（头部券商对外披露、券商金工公开评测维度、小券商 IT 投入增速）。方向上没有判断错误。
2. **但本项目主张的两个对外卖点都已被市场否定**："多智能体平台"在 2026 年的传播与采购语境里几乎不存在；"可溯源/防幻觉"已完全商品化（开源免费且活跃、商业公司无一单列计价、原头部玩家已转行），**无法单独支撑付费**。
3. **本项目当前的市场需求度无法被证实为大于零**，原因是事实层面的：GitHub 1 star / 0 fork / 0 watcher，全渠道零外部提及；本地数据库显示 477 个任务中约 50% 是自测重复场景，真实外部使用量约等于个位数。这不是"市场不要"，而是"从未有一个外部用户跑到看见价值的那一步"。
4. **唯一有实测支撑的资产是 A 股/港股结构化链路**（A 股日报任务做到过 85% 数字溯源），而独立实测的美股链路是 8% 数字溯源、**0% 金额溯源**。美股链路失效的根因（SEC EDGAR 结构化数据未接到 target 上）在项目自己的实测报告里已被定位——这是可修的具体缺陷，不是能力天花板。
5. **演进建议：从"通用多智能体平台"收敛为"可复核的上市公司研究工作台"**，以 A 股/港股链路为轴把"数字能从底稿重算"做成产品事实而非营销话术；变现走"个人免费 / 团队与合规付费"（对标 OpenBB Lite $1,200–2,400/年、Tabby $19/座/月）；获客主渠道是中文技术社区（掘金/公众号的"本地部署+垂直教程"），不是 Hacker News。
6. **前置条件：先让"从零 clone 到第一份可用报告"在干净环境里跑通**，否则以上任何方向都无从验证。这是当前唯一阻断一切的关卡。

## 二、需求度评估：分三层看

### 第一层：赛道需求——存在，但可寻址的钱比新闻标题小一个数量级

| 事实 | 数值 | 来源 |
|---|---|---|
| AI agents 市场规模 | 2025 年 79.2 亿美元 → 2026 年 115.5 亿美元；CAGR 43.57%（2026–2035） | Precedence Research，报告更新 2026-07-01 |
| 企业 GenAI 支出结构 | 横向 84 亿美元（同比 5.3 倍），其中 copilot 占 86%（72 亿），**agent 平台仅 10%（7.5 亿）** | Menlo Ventures《2025: State of Generative AI in the Enterprise》，2025-12-09 |
| "真 agent"占比 | 企业部署中仅 **16%**（初创 27%），其余是有固定序列/路由的单次调用 | 同上 |
| 垂直 AI 总盘子 | 35 亿美元，其中医疗 15 亿领跑，**金融未单列** | 同上 |

**解读**：headline 的 115 亿美元是"AI agent 概念"的 TAM，不是"agent 平台"的可寻址收入池。企业真正在 agent 平台上花的钱是 **7.5 亿美元量级**，且只有 16% 的部署称得上真 agent。垂直 AI 里金融连独立统计都没进——**"AI 投研"在 2026 年还不是一个被测量出来的独立市场**。这既是机会（无垄断者）也是警告（别按大市场做规划）。

### 第二层：需求方向——与业界真实痛点部分吻合，但两个卖点落空

**吻合的部分**（LangChain 调研 1,300+ 从业者 + HN 2025-2026 讨论双向印证）：

- 用户最想要的管控能力是 **tracing/observability**，其次离线评测（39.8%）> 在线（32.5%）
- 首要障碍是**性能质量**（小公司 45.8%，成本仅 22.4%）
- HN 上反复出现的三类抱怨：agent 失败源于环境不稳（缺依赖、状态脏、反馈回路不清）而非模型错；**成本失控**（AgentGuard、Guardian Runtime 等一串 Show HN）；**权限无范围**（30 个 agent 项目里 93% 用无范围限制的 API key）

本项目内置的沙箱隔离、成本预算降级、审计日志、Worker 守护，正好落在这三处。这部分是真实需求。

**落空的部分**：

1. **"溯源/防幻觉"作为独立卖点没有付费市场**。证据链完整：
   - 能力已开源且活跃：RAGAS 15,752★（Apache-2.0，push 2026-02-24）、DeepEval 18,292★、promptfoo 25,177★、Arize Phoenix 11,488★、Vectara HHEM-2.1-Open 与 hallucination-leaderboard 3,313★
   - 商业公司**无一家把它单列计价**：Galileo、Arize AX、Fiddler 的免费档即 unlimited evals；Braintrust、LangSmith 按 trace/seat 计
   - 原头部玩家已转向：Patronus AI 官网首页从幻觉检测转向 "Digital World Models"
   - 社区注意力极低：HN 近一年 "hallucination detection" 帖子得分全部 ≤7，多数 0–3
   - 监管时点不对：EU AI Act 第 12/13/15 条（日志记录、精度指标写入使用说明）适用日是 **2027-12-02 / 2028-08-02**；2026-08-02 生效的是第 50 条（合成内容机器可读标记）——**2026 年的硬性触发是"AI 内容标记"，不是"引用溯源"**

2. **"多智能体平台"这个词在 2026 年的高分传播里几乎不出现**。对 2025 年至今 HN 得分 >250 的 100 条帖子做标题统计：含 `multi-agent` = **0 条**，`framework` = **0 条**，`workflow` = **0 条**，`platform` = **1 条**。同期赛道已过度拥挤：n8n 204,548★、AutoGPT 187,382★、Dify 155,939★、CrewAI 58,652★、LangGraph 41,760★。且 HN 上 "Does anyone use CrewAI or LangChain anymore?"（2026-02-24）最高赞回复是 **"No. They suck."**，另有从业者直指 "abstraction soup makes debugging a nightmare in production"。被弃养的案例也已出现：MetaGPT 自 2026-01-21、Microsoft AutoGen 自 2026-04-15 停滞。

3. **"本地优先"是准入门槛，不是差异化卖点**。反面证据：Menlo 数据显示企业开源 LLM 占比从 19% **降到 11%**。正面证据：本地生态规模仍巨大（Ollama 181,119★、Open WebUI 152,269★、llama.cpp 128,418★），主权 AI 情绪强（HN "Apertus – Open Foundation Model for Sovereign AI" 534 分）。**结论：在金融行业，"本地"是采购的硬性前提（见第三层），因此人人都有，不能当卖点讲。**

### 第三层：金融投研细分——需求真实，且买方用的评价标准正好是"可复核"

中国市场本节证据质量最高，且**三条互相独立的证据指向同一个需求**：

| 证据 | 内容 | 来源 |
|---|---|---|
| 华泰证券对外披露 | Skillhub 上线 32 款投研专属技能、日均支撑 5,600+ 计算任务、沉淀 3 万余投研因子；已建**国产化 GPU 私有云**；明确写入"强化数据统一校验、**资讯来源溯源双重管控，从源头规避 AI 幻觉**" | 证券时报，2026-09-14 |
| 国金证券金工公开实测 | 对估值建模/多因子回测/行业研究三类任务评测，评分维度含"**底稿可重算**""来源标注""**评分可复算**" | 第一财经，2026-09-11 / 2026-09-16 |
| 讯兔科技（Alpha派） | 完成超 3 亿元 B 轮，自披露服务超 8 万名投研人员、6,000+ 家机构、头部渗透率 90%（**公司自述，无公开合同佐证**） | 科创板日报，2026-09-10 |

**"溯源"在这里不是开发者的自嗨，而是买方已经在用的评分维度**——这是本报告最重要的正面发现。

**本地化是既成采购事实**（不是软性偏好）：

- 浙商银行"智能体基础软硬件"采购由北京可利邦中标 **6,489.61 万元**，加 946 万元"财富及供应链智能体"，8 月合计约 **7,436 万元**（财联社，2026-09-14）
- 行业表述："本地化部署是金融业 AI 未来发展的必然趋势。数据安全、保密、合规等多方面的要求意味着金融机构的大量资料无法上传至云端"（上海证券报，2026-09-16，品高股份/慧博）
- 同花顺把机构端定义为"**将投研数据能力接入客户本地 AI 环境**"（界面新闻，2026-09-09）
- 中小券商 IT 投入占营收不足 3%，头部 8–10%（财联社，2026-09-15）

**但散户与自媒体端的付费路径被证据削弱**：

- 证监会 **2026-09-11 同时公布四份处罚**：长江证券宗建树（编造，5 年市场禁入）、马星瑞（原文转发，罚 30 万）、**卢润凯（用某 APP 生成文章并全文发布，罚 20 万）**、陈广华（103 万粉丝博主，罚 20 万）。**四人均无违法所得仍被认定违法**
- 2026 年 8 月四川证监局：**个人投资者**用 AI 编造虚假信息，没收违法所得 8.5 万 + 罚 40 万
- 证券时报评论原文："具备 AI 功能的 APP 工具可提升内容生产效率，**但不能作为编造虚假信息的挡箭牌，使用 APP 生成内容同样要对信息真实性负责**"
- 《人工智能生成合成内容标识办法》及配套**强制性国标 2025-09-01 已施行**，要求 AI 生成内容显式+隐式标识
- 《金融产品网络营销管理办法》**2026-09-30 施行**，确立"先持牌、再认证、后营销"；小红书处置违规金融笔记超 101 万篇

**含义**：面向散户做"AI 生成投研内容"的合规风险已从灰色落到**已被实际处罚的区间**；而持牌机构内部做"辅助+署名+底稿留痕"是被鼓励方向。这直接决定了产品的可服务客群边界。

### 3.2 内部使用事实

- `agents.db`：`task_history` **477 行**，跨度 2026-07-24 → 2026-09-16（54 天）；SUCCESS 288 / FAILED 124 / SUCCESS_WITH_ISSUES 60 / CANCELLED 5。其余表几乎为空：`sessions` **2 行**、`checkpoints` **1 行**、`agents` 11 行。
- **任务数被自测场景严重稀释**：477 个任务只对应 **185 个不同 goal**；出现 ≥5 次的 goal 有 23 种、覆盖 **240 个任务（50%）**——贪吃蛇 24 次、愤怒的小鸟 20 次、AI 芯片市场 25 次、字面量"目标" 16 次。项目字段中 `架构试用-20260915` 仅 **2 个任务**。
- **用户维度**：distinct `user` 只有 3 个值——空 459、`scheduler` 10、`momang` 8。即**真实外部使用量约等于个位数**。
- **指标台账不可用于结论**：`metrics_summary.json` 报 success_rate 60.4%，但 `avg_latency_sec` / `p95_latency_sec` / `critic.pass` / `replan.total` 全为 0（未真正采集）；`cost_usd_total` 仅 **$0.6169**（477 个任务合计），折算单任务约 $0.0013——与"生成一份投研报告"的成本量级不符，反证这批任务绝大多数是轻量自测。
- **工程投入远超真实使用**：36 个 `test_*.py`、约 1,306 个 test 函数、51MB 日志/50 个文件、323 次提交。这是单人高频开发+自测的典型形态。

### 3.3 质量事实：核心卖点尚未成立

| 场景 | 数字溯源率 | 金额溯源率 | 来源 |
|---|---|---|---|
| A 股活跃度日报（README 引用） | **85%**（206/241） | — | README.md:37 |
| WBD 美股任务（独立实测） | **8%**（3/37），模型知识 18 处 | **0%**（0/17） | `新手实测报告_20260914.md:90-93` |
| 传奇影业任务（独立实测） | **0 个数字可核**，15 处数据缺失占位 | — | 同上 |
| 财务任务（试运行） | 46% | 53%，12 处占位，**同一目标两次复现** | `试运行报告_20260912.md` |

独立实测报告的根因定位（原文）："金额溯源 0% 的根因不是'没搜到'，而是**结构化财务数据没接上**……工作区里没有 `financials.json`，说明 SEC EDGAR/东财结构化适配没接到这条 target 上"。

**两个必须正视的问题**：

1. **README 只引用了最好案例（85%），未披露区间（8%–85%）**。85% 是 A 股专门任务；同一个系统在美股任务是 8%。README 的诚实性直接关系到"可信交付"这个立身之本，这个披露缺口应当补上。
2. **README 已自认的盲区仍然存在**：数字溯源"只校验数值与来源是否出现，不绑定数值-主体归属"——即报告写 A 公司、来源是 B 公司同数值时仍判为可溯源。国金证券的评测维度恰好是"底稿可重算"与"来源标注"，本项目目前的实现**过不了这道买方标准**。

### 3.4 落地门槛：三道路障都在"看见价值之前"

独立实测（`新手实测报告_20260914.md`）记录的三处阻断：

1. **便携 Redis 下载卡死**：源为 GitHub releases，国内网络等 400 秒无返回只能中断，报错仅英文兜底提示——**这是中国用户的第一次接触点**
2. **登录/初始化白屏**：React error #300/#310，必须手动刷新
3. **冷启动竞态**：首次启动 15/16 服务、编排器静默死掉（卡在 redis-py 重试循环），提交任务无反应且无诊断

这三项在后续提交中已修复，但**"从 GitHub 真 clone 到出第一份报告"这条路径从未在干净环境中被验证成功**（实测中因代理不可用根本没走到）。

独立测试者的结论原文："**是'高级草稿生成器'，还不是可交付的投研工具**"。

## 五、演进方向建议

### 5.1 定位重写（一句话）

**现在**：一支看得见、会记忆、会自我进化的 AI 团队，跑在你自己的电脑上（多智能体平台 + 全链溯源）

**建议**：**"可复核的上市公司研究工作台：每个数字都能回溯到底稿并重算。"**

理由：`multi-agent` / `framework` / `platform` 在 2026 年高分传播里出现 0–1 次；而"底稿可重算""来源标注"正是国金证券公开评测在用的买方语言，也是华泰对外披露的用词。**多智能体是内部实现，不该是对外承诺**——对外只留一个场景、一句可验证的话。

### 5.2 产品动作（按优先级）

**P0 — 让"从零到第一份报告"在干净环境跑通（唯一阻断一切的关卡）**

- CI 增加"容器内从零 clone → 装依赖 → 起服务 → 提交任务 → 产出报告"的端到端门禁
- 便携 Redis 在中国网络下的下载改多源（国内镜像 + 系统 Redis 优先探测），失败给出中文可执行指引
- 明确"第一次运行"的成功定义与自动自检输出

不做这一步，其余方向都无法被验证。

**P0 — 补齐海外结构化财务链路，并把"数字-主体-报告期-来源"硬绑定**

- 独立实测已定位根因：SEC EDGAR 适配没接到 target 上、工作区无 `financials.json`
- README 自认的盲区（数值与来源出现即判可溯源，不绑定主体）必须修——这是能否对上"底稿可重算"的唯一门槛
- 把 `8%–85%` 的区间连同任务类型写进 README，替换现在的单点 85%

**P1 — 把"溯源"从卖点降级为质量内建，把"可复核交付物"升级为卖点**

溯源校验已商品化（见第二节），继续当卖点是投入产出比最低的选择。真正稀缺的是：**一份分析师敢署名、底稿能重算、留痕可审计的研究稿**（含 AI 生成标识的合规包头、免责声明模板、数据时效卡、导出可编辑底稿）。项目已有这些组件，只是叙事摆错了位置。

**P1 — 收敛功能面，砍掉通用平台叙事**

现有 11 个 Worker + 6 类数据适配器 + 模板库 + 进化锦标赛 + MCP 兼容，对一个还没有外部用户的项目而言是过宽的战线。建议以"上市公司研究"一条链为主线，其余能力标记为可选或隐藏。

### 5.3 变现路径

模式已被验证：**本地/社区版免费，钱出在团队、托管、合规上**——n8n（自托管 Business €667/月，$180M C 轮）、LangChain（LangSmith $39/座/月，$125M B 轮）、OpenBB（Lite $2,400/年，促销 $1,200，自托管 <10 人）、Tabby（$19/座/月，≤5 用户免费）、Msty（$149/用户/年 或 $349 买断）。

建议定价锚点：**个人与研究者免费自部署；团队版对标 OpenBB Lite 的 $1,200–2,400/年区间；机构私有化按项目询价（不公开标价——该赛道全部是询价制，AlphaSense 中位年合同 $18,000、Bloomberg 终端 $24,000–27,000 均为第三方样本，非官方）**。

进入持牌机构的现实路径是**被金融 IT 集成商集成为组件**，而非直销。

### 5.4 获客路径

**主渠道是中文技术社区，不是 Hacker News。** 证据：Dify 的 Show HN 仅 4 分/1 评论、OpenHands 11 分/1 评论，但今天分别 155,939★ / 88,130★；而中文侧"用 Ollama + DeepSeek + Dify 搭建本地知识库"单篇掘金阅读 25,642。**star 与中文"本地部署教程"密度强相关。**

2. README 首屏只留 30 秒 GIF：一句话输入 → 出研报 → 点某个数字弹出溯源卡片（`docs/hero-demo.gif` 已存在，直接上首屏）

## 六、明确不建议做的事

1. **不要再做"又一个多智能体框架"**。赛道已饱和，头部三个框架合计 16 万 star，HN 评价是 "No. They suck."，2026 年新增框架几乎全部 0 评论。
2. **不要把"溯源"做成独立产品或 API 对外收费**。开源免费品已齐备且活跃（RAGAS / DeepEval / HHEM / Phoenix），商业公司无一家单列计价，Patronus 已转行。
3. **不要碰散户荐股/投资建议/收益预期**。证监会 2026-09-11 四案已确认"AI 不是挡箭牌"，且含个人投资者被判罚 40 万的判例；《金融产品网络营销管理办法》2026-09-30 施行，"先持牌、再认证、后营销"。
4. **不要用无出处的市场数字做决策**。仓库既有 5 份商业文档中 2 份零引用、1 份仅 3 条外链；请以本报告的"有据/推测"分层为准。
5. **不要以 Rogo/AlphaSense/Hebbia 的用户数论证 TAM**。它们是询价制大户，客群（5 万席位、350 机构）与开源个人/中小机构市场不重叠；且 Rogo 三个月估值从 7.5 亿到 20 亿美元（2.7 倍）是**过热信号**而非需求证明。
