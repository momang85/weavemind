# 机构私有化 POC 目标名单（20 家，按触达难度排序）

**背景**：商业化路线报告③号动作——机构扩展的三大障碍（数据安全 29% / 集成难 21% / 幻觉风险 16%）
恰好被织光已有的"本地 LoRA 推理 + 审计日志 + Docker 全栈 + 全链溯源"解决。
本名单按"最容易开口→最难"排序，供逐家 POC 触达。

## A 组：财经自媒体/内容团队（最先试，决策链短，日报产品直接对口）

| # | 目标 | 痛点对位 | 触达方式 |
|---|------|---------|---------|
| 1 | 财经公众号矩阵运营团队（雪球/公众号万粉以上） | 每天写行情复盘费 2-4 小时 | 免费日报订阅 + 溯源 API 试用 |
| 2 | 财经短视频脚本团队 | 素材收集慢、数据核对无底 | 日报 CSV + 溯源页 |
| 3 | 财经播客主理人 | 需要日更选题与数据支撑 | 日报邮件订阅 |
| 4 | 知识星球财经博主 | 会员需要差异化内容 | 深读包白标授权 |
| 5 | 券商营业部投教内容岗 | 合规要求溯源、效率要求量产 | 溯源 API 嵌入其公众号工具链 |

## 开口话术模板（一句话）

> "你们的 AI 报告能证明每个数字来自哪里吗？我们做了一个开箱即用的
> 溯源体检——把任何研报丢进来，30 秒告诉你多少数字可验证、哪些是
> 模型猜的。日报产品免费试，机构版数据不出你服务器。"

## 衡量标准

- 90 天内：≥20 家触达 → ≥5 家演示 → ≥1 家付费转化（任一档）
- 免费日报订阅转化率 ≥3%
