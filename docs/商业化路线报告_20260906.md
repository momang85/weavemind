# 织光 WeaveMind 商业化路线报告（2026-09-06）

**定位主张**：**可溯源的投研信息工具**——不碰投顾建议，卖"每个数字都有出处"的信任基础设施

---

## 一、市场事实（外部证据）

| 事实 | 数字 | 对织光的含义 |
|------|------|-------------|
| 金融 AI 已主流化，但部署深度不足 | 93% 在用/评估，仅 25% "fully integrated"（[Hebbia 2026](https://www.hebbia.com/resources/ai-trends-in-financial-services-2026)） | 早期窗口仍在：深度集成者建立持久优势 |
| 生产力收益已被验证 | 63% 每周省 6h+，27% 省 10h+ | "省时间"是可量化的价值主张，支撑订阅定价 |
| 信任是有条件的 | 85% 信任可验证来源的输出；无法验证时信心暴跌 | **溯源链就是购买理由**——织光的验收器/三档分类/来源卡片正踩在点上 |
| 幻觉检测自成超级赛道 | $1.94 万亿(2026)→$26.66 万亿(2035)，CAGR 33.8%；亚太增速最快 39.8%（[Precedence](https://www.precedenceresearch.com/ai-hallucination-detection-market)） | 织光的验收器可独立为"检测/审计"卖点，甚至 API 化 |
| 监管强制 audit trail | 模型输出审计留痕正成为强制要求（欧盟 AI 法案/各国监管） | 溯源页 = 合规基础设施，机构刚需 |
| 中国散户正在机构化 | 证券 App 月活 1.73 亿；46% 散户已把"AI 投顾+算法单"当首要方式，2027 预计 80%（[证券时报](https://stcn.com/article/detail/3354537.html)） | C 端日报/简报有海量且快速增长的需求池 |
| 券商已重兵布局 AI 投顾 | 20+ 券商 T0 算法服务；华林复购率 92%；监管要求算法备案 | **正面刚投顾 = 找死**；做"信息工具"层 = 券商是潜在渠道/客户而非对手 |
| 机构扩展的三大障碍 | 数据安全(29%)、集成难(21%)、幻觉风险(16%) | 私有化+本地 LoRA（已有）+审计日志（已有）正对前两项 |

**一句话**：市场付钱的理由恰好是织光最强的部分（可验证、可溯源、可审计），而织光不碰的部分（投顾建议、交易闭环）正是监管最严的部分——定位天然安全。

## 三、接下来做什么（按优先级排序）

### ① 每日 A 股活跃度日报（本周即可启动，最快验证商业闭环）
- **为什么先做**：排行链路已验证（5555 行全市场数据→TOP10→图→报告 6.5 分钟）；scheduled-jobs 已有；日报是**日更内容资产**，自带传播与回访
- **怎么做**：收盘后 16:00 定时跑 → share page 落地页（TOP3 结论卡片+溯源区块+CSV 下载）→ 公众号/企微 webhook 推送
- **变现路径**：免费日报引流 → 付费深读（量价关系/历史回看/CSV 全量）¥9.9-29/月
- **衡量**：30 天内日报 DAU、分享率、付费转化 ≥3%

### ② 数据溯源页 API 化（把最强资产变成独立卖点）
- **为什么**：幻觉检测是 33.8% CAGR 的赛道；验收器（三档分类/死链检测/算术验证）已有 90% 完成度
- **怎么做**：`POST /verify {report_text, sources}` 返回结构化溯源报告——给自媒体、券商内容团队、甚至其他 AI 应用做"报告体检"
- **变现**：按次计费 API（如 ¥0.1-0.5/千字）或作为机构版捆绑能力
- **衡量**：API 调用量、被集成方数量

### ③ 机构私有化 POC（瞄准 2-3 家试点）
- **为什么**：机构扩展障碍 Top2（数据安全 29%/集成 21%）恰好被"本地 LoRA 推理 + 审计日志 + Docker 全栈"解决——这三样织光都已有
- **怎么做**：找小型私募/财经自媒体团队做免费 POC（自备 LLM key 或纯本地模式）；用"数据不出域"叙事
- **变现**：私有部署年费（¥3-10 万/年，按席位）
- **衡量**：90 天内 1 个付费 POC 转化

### ④ 深研模板包产品化（把已验证的三条链路定价）
- 个股深研（9 分钟链路）/ 基金对比 / 宏观策略已验证，按链路+反思轮数分级计费
- 免费额度（如 3 次/月）+ 订阅制（¥99-199/月）

### 暂不做（明确排除）
- ❌ 投顾建议/买卖点位（牌照红线，且已建立合规护栏）
- ❌ 交易闭环（与券商正面竞争，无胜算）
- ❌ 自研行情数据源（成本黑洞；先用授权/合规通道，adapter 层已留切换位）

## 四、定价建议（基于市场信号）

| 层 | 内容 | 定价 |
|----|------|------|
| 免费层 | 日报 + 每月 3 次简报生成 | ¥0（获客） |
| 个人专业层 | 无限简报 + 深研模板 + CSV 导出 + 溯源页 | ¥99-199/月 |
| 团队/API 层 | API 额度 + webhook 分发 + 多项目 | ¥999-2999/月 |
| 机构私有层 | 全栈私有部署 + 本地推理 + 审计导出 | ¥3-10 万/年 |

锚点：券商提佣包已证明散户愿为 AI 工具付费（华安覆盖用户 +67%）；织光个人层定价低于券商投顾包、高于纯订阅媒体，卡在"专业工具"心智。
