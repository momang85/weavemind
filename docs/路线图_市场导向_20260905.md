# 织光 WeaveMind 市场导向路线图（2026-09-05）

**依据**：《试运行报告_功能详评与优化建议》（U1-U6 用户建议 / B1-B6 商业建议）+ 2026 市场信号检索
**定位主张**：**"可溯源的投研信息工具"**——不碰投顾建议，卖"每个数字都有出处"的信任基础设施

---

## 一、市场需要什么（2026 年信号 → 对织光的含义）

| 市场信号 | 证据 | 对织光的含义 |
|---------|------|-------------|
| **信任与可溯源是第一购买标准** | 2026 Q1 AI 幻觉致 23 亿美元交易损失；可解释性/可溯源正从"功能"变成"合规要求"；幻觉检测自成赛道 | 织光的验收器/溯源链/数据时效卡恰好踩在市场最痛的点上——**这是核心资产，不是附属功能** |
| **金融机构从实验转向生产部署** | Hebbia 2026 趋势报告：机构比拼的是把 AI 放进生产流程 | 私有化部署 + 审计日志（已有 audit_log）+ API 是机构付费入口 |
| **中国散户"机构化"，AI 投顾猛增** | 证券时报：AI 工具把散户批量改造成"微型机构"；日报/研报摘要需求快速上升 | 每日活跃度日报有真实且巨量的 C 端需求 |
| **牌照是分水岭** | 界面/东财：投资咨询属特许经营，无牌第三方提供"投资建议"是红线 | **产品话术必须定位"信息整理与数据工具"**，报告已经内置免责声明——把这个纪律执行到底，反而成为合规卖点 |
| **AI 幻觉研报乌龙成治理重点** | 经济参考：券商投研 AI 幻觉错误正被整治 | "发布级图表分级 + 全链溯源"是差异化叙事 |

**一句话**：市场不缺"会写研报的 AI"，缺的是**"敢把每个数字的出处亮出来的 AI 投研流水线"**。织光刚刚用一次 20 分钟的运行证明了自己就是这个东西。

## 二、四阶段路线图

### Phase 0｜止血与地基（1-2 周，工程）
> 目标：把"能演示"变成"敢交付"

| 事项 | 对应 | 验收标准 |
|------|------|---------|
| 修复 BUG-9~13（散点去重误杀/坏图残留/图名错位/标签乱码/来源 URL 校验） | 试运行报告第三节 | 排行任务图表 100% 发布级；用户点名的图必出，失败则报告头部明示 |
| 反思预算按链路分级（排行 2 轮/个股 3 轮/宏观 3 轮）+ 派生数字豁免（U3/B2） | 成本 -30%、误重做清零 | 排行任务 ≤12 分钟；单任务 token 成本台账可见 |
| 端点账单监控告警（402/401 前置发现，而非运行中降级） | B1 | 余额 < 阈值时任务提交前预警 |
| 会话持久化（重启不掉登录态） | 架构短板 | webui 重启后会话存活 |
| charts "发布级/草稿级"分级（B5）：发布级不达标不进正文 | 用户信任 | 乱码图零出现 |

### Phase 1｜把"每日 A 股活跃度日报"做成产品（3-6 周，产品）
> 目标：用已验证的排行链路做出第一个可增长的内容资产（C 端引流 + 自媒体 B 端效率工具）

| 事项 | 说明 |
|------|------|
| scheduled-jobs 产品化 | 已有定时任务能力：每日收盘后自动跑排行链路，产出标准日报 |
| 日报落地页（share page 进化） | TOP3 结论卡片置顶（U2）+ 五要素图表 + 数据溯源区块 + ranking.csv 下载（B3 引流品） |
| 分发渠道 | 公众号/邮件/雪球等渠道推送；每篇日报尾部带"生成同款报告"入口（产品自传播） |
| 免费日报 + 付费深读 | 免费：TOP10 榜单+板块归纳；付费：量价关系深读+历史回看+CSV 全量 |
| 合规话术固化 | 全站"信息工具，不构成投资建议"；不输出个股买卖点位（无牌红线） |

**衡量**：日报 DAU、分享率、订阅转化、单篇生成成本。

### Phase 2｜溯源即卖点 + 深研包（6-12 周，商业化）
> 目标：把内部质量分变成对外承诺与付费点

| 事项 | 说明 |
|------|------|
| 数据溯源报告页（B2） | 每份报告附"溯源页"：N 个数字、M 个可溯源、K 个计算值（附推导式）、J 个模型知识已标注——把验收器输出转译成用户语言（B6） |
| 深研模板包 | 个股深研（9 分钟链路已验证）/ 基金对比 / 宏观策略，按链路定价（B4） |
| API 开放 | POST /task + webhook 回调 + 溯源页——面向小微机构/量化爱好者的第一层 B 端收入 |
| 前端体验兑现 | U4 步骤降噪（用户视图/机器视图分离）、U5 耗时预估、U6 图表放大与单图下载 |

**衡量**：付费订阅数、API 调用量、溯源页打开率、NPS。

### Phase 3｜平台化与机构版（3-6 个月，护城河）
> 目标：从产品变平台，吃机构私有化与合规市场

| 事项 | 说明 |
|------|------|
| 巨石拆分 | orchestrator_v2（7600 行）按域拆：编排/反思/图表管线/验收/模板固化为独立模块；web_ui 路由层独立——开发速度与机构交付的前提 |
| 单一推送源 | 任务状态收敛到 SSE 推送，轮询降级为兜底——去掉双通道复杂度 |
| 数据源官方化 | 与行情数据商谈授权（当前爬取新浪/东财有合规风险），adapter 层已为切换做好准备 |
| 机构私有化包 | Docker 全栈部署 + 审计日志导出 + 权限体系（已有 admin/viewer）+ 本地 LoRA 推理（数据不出域——已有 lora 管线，是隐私叙事的现成筹码） |
| 适配器 SDK | 第三方数据源/模板市场，生态卡位 |

## 三、风险与对策

| 风险 | 对策 |
|------|------|
| 无投顾牌照 | 全站定位信息工具；免责声明强制注入（已实现）；不做个股推荐/点位 |
