## 0. 先修自己造成的回归：`net_policy.fetch_document` 读之前就关了连接

| 项 | 内容 |
|---|---|
| 现象 | 任何经内容抓取通道的取件恒失败：`FetchError: 响应解析失败：OSError: [WinError 10038] 在一个非套接字上尝试了一个操作` |
| 根因 | A1 重做（`9db98f2`）把响应解析换成 `http.client`，却把旧的"先收字节 → `finally` 关连接 → 再手拆头"顺序留下了：socket 已关，解析必然失败 |
| 为什么离线全绿 | 替身的 `close()` 是空操作，且 `makefile` 交的是**完整副本**——绿的是替身，不是生产路径 |
| 影响面 | `material_intake` 直链取件（补材料入口）、`workers/web_fetch_worker`、`workers/data_loader_worker`、`adapters/url_health` |
| 修法 | 不预读、不提前关闭：`_read_http_response` 自己按截止线读，读完（或报错）才关；顺手把**多地址重试共用一条根截止**补上（重试不续期） |
| 验证 | 忠实替身（关后即报 10038、`recv` 与 `makefile` 共用游标）→ 旧实现上该用例**必失败**、新实现 50 OK；真机 `fetch_document` 取回 cninfo 证券索引 `200 / 592391 字节 / 6258 条` |

## 1. 更正 09-07 的结论：巨潮公告查询**不是**被挡，是参数缺 orgId

| 端点 | 参数契约 | 实机读数 |
|---|---|---|
| `POST /new/hisAnnouncement/query` | `stock="{code},{orgId}"`（**裸代码会静默空**）、`column=szse`、`category=category_ndbg_szsh`、`seDate=披露日窗口` | 600031：200 / 4 条年报类；000711：200 / 17 条 |
| `GET /new/data/szse_stock.json` | 无 | 200 / 592391 字节 / **6258 条**（含沪深全部 A 股）；`sse_stock.json` 404 |
| `GET query.sse.com.cn/...queryCompanyBulletinNew.do` | 需 Referer | 200 但 `pageHelp.data` 为空数组 → 记为**未打通**，不写成"交易所封了我们" |

**交叉验证（关键）**：发现链自己找出的京蓝 2020 年度报告（更正后）URL 与用户此前提供、
已准入过的直链**逐字符一致** → `http://static.cninfo.com.cn/finalpage/2025-09-05/1224639904.PDF`。

`seDate` 过滤的是**披露日**而非报告期（京蓝 2020 年报的更正版 2025-09-05 才发布）：
因此窗口右端默认开到"现在"，要问"当时能看到什么"必须显式传 `until`。
实机：`until="2021-12-31"` → 只剩原版（2021-04-27）；不传 → 原版与更正版**并存**。

## 3. 抽取器认三种真实版面（A0 的"宁可拒绝"不变，只是不再把可读的行判成不可读）

三家公司都是**同一版代码、同一套判据**读出来的（无按公司分支）。

| 版面特征 | 实机形态 | 处理 |
|---|---|---|
| 行项目前缀 | `一、营业总收入 78,383,379 …`、`其中：营业成本 七、54 …`、`减：营业成本 …` | 编号与"其中/加/减"是格式，先剥掉再**完整标签**匹配 |
| 附注列引用 | `应收账款 七、6 25,516,530 24,164,729` | 引用夹在标签与金额之间，先剥掉（不是金额） |
| 折行标签 | `归属于上市公司股东的净利润` + `(元)` + 金额行；`…净利润(净亏损` + `以“-”号填列) 5,975,451 …` | 最多看两行续行；续行**不得含数字**（否则是被截断的数 → 拒绝，见下） |
| 期末/期初列头 | 洋河 `项目 期末余额 期初余额`（表头不写年份） | 年份取**报表日期行**（`2024 年12 月 31 日`）→ 列头 `2024年 / 2023年`，来源记 `end_start` |
| 分页重复表头 | 三一利润表：表头 4990、归母净利行 5022 | 表内向上找最近表头（遇报表标题/非报表小节即停） |
| 单位标注只在报表开头 | 三一现金流量表：单位在 5122、期末行在 5156 | 表内向上找单位标注（同样的停止条件） |
| **不是**报表的同名表 | `合并利润表影响`（政策变更说明）、`首次执行新收入准则调整年初财务报表` | 标题附近有"政策变更/追溯调整/首次执行"或表头含 `调整数/新准则/原准则` → 不取 |

**反例（宁缺毋错，仍拒绝）**：
`应收账款` / `1,279,570,42` / `9.23 1,966,154,875.23` 这种**被排版截断的数**不得当成折行金额
（否则 12.79 亿会被记成 9.23 元）；年初/期初列不占本年那一格；表头年份与金额个数不等一律拒绝。

定向：`python test_annual_financial_tables.py` → **28 OK**（原 15 + 新增 13）。

## 5. 口径显式化：真实年报同时有合并/母公司

**新发现的缺陷**：`AnalysisDataset.get()` 的"同一 (指标,期间) 多条 = 冲突 → 返回 None"规则，
在真实年报（合并 + 母公司两张表都抽得到）下会让**所有**模型报"缺输入"——数据齐备却一个模型都跑不出。

修法不是"随便挑一条"，而是把口径选择**显式化**：
`primary_caliber` = 有合并就用合并；只有一种口径时才默认那一种；否则 `""`（不可默认）。
同一口径内出现两个不同值**仍然** `None`；显式 `caliber="母公司"` 可取母公司。
定向：`python test_financial_analysis.py` → **63 OK**（原 57 + 新增 6）。
