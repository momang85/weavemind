### P0-6 交付成功，但页面同时告诉你「没有可复算输入、没有事实来源、无法离线补算」

四个页签里都渲染着同一句（截图 `09-tab-补材料.png`、`09-tab-项目结果.png`）：

> 该任务没有可复算输入（`analysis/dataset.json`），且工作区没有本次任务的事实来源
> （`project/working_paper.json` 与 `project/financials.json` 均不存在）：**无法离线补算**。
> 要么补一份披露材料（材料页→补材料），要么重跑研究；系统不会用猜测的数据补齐。

事实核对：任务目录 `project/` 下确实只有 `chart_manifest.json`、`clean_chart_data.json`、
`haitian_financials.csv`、`make_charts.py`、`official_discovery.json`、`search_results.json`、
`topic_terms.png`——**没有** `working_paper.json` / `financials.json` / `analysis/dataset.json`。
即：这条提示是**准确的**，而它准确说明的是「这份以 `SUCCESS_WITH_ISSUES` 交付的报告没有任何可复核底稿」。

配上正文 §1.3 自己写的「本次报告**不能给出 6 个目标数据点中任何一个的可用数值**」，
用户在同一个屏幕上读到的是：状态=交付（带瑕疵）、头部卡片=7/7 成功、正文=什么都算不出来、
补算面板=无法离线补算。这是本轮**最像「用户一眼就会发现」的问题**：
产品定位是「可复核的研究交付」，而这次交付里没有任何可复核的东西，页面却没有任何一处
把这件事上升为显式结论（不阻断、不降级为「材料不足未交付」）。
