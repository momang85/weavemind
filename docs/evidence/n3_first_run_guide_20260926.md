## 2. 实机验证

```
GET /api/auth/bootstrap → {"setup_required": false, "config_complete": true, "demo_available": true}
GET /api/demo/brief     → available=true, title=内置演示简报（合成数据）,
                          note=内置演示：非本次实时生成，不代表真实研究结果；不写入任何研究统计,
                          markdown 1173 字符且正文含"非实时生成"标注
```

服务重启（`launcher.py restart`，16/16 存活、三层就绪）后：

- 前端产物已重建（`npm run build`），构建出的 `TaskConsole-*.js` 内含
  `首次使用引导` / `非本次实时生成` / `不自动提交` 三处文案——即引导确实进了被伺服的前端；
- **浏览器内渲染未由我验证**：服务重启后浏览器会话在旧标签页，新建标签页只到登录页
  （登录表单已有内容，但我不持有凭据、不猜密码）。这一步留到 N4 的真人路径验收，
  不写成"已通过"。

新增用例：

- 后端：`bootstrap` 只暴露布尔（字段集固定、不得回显密钥/地址/模型名；配置不完整时为 False）；
  演示接口公开可读、标注必带"非本次实时生成/不写入"、写操作不被接受；演示文件缺失时如实 404。

  示例目标只填入不提交；读结果一步含三态与"逐问题资料计划/重新导出"；引导不自建密钥输入、
  配置入口指向既有设置页。
