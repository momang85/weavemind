## 边界（如实记录）

- 本机（Windows）渲染通过**不能**代表 Linux：字体覆盖差异只会在对应环境复现。
  已知 Linux 独有的两个渲染缺陷由 CI 日志定位并已修（cmap 只留一个子表导致 ASCII 取不到
  字形；字体缺字形时留白），修复手段是合并全部 cmap 子表 + 缺字形回退内置 Helvetica。
  Linux 侧的最终确认仍需 CI 绿灯或 `scripts/pdf_visual_check.py` 在 Linux 上跑一次。
- 本文件覆盖的是**排版**（分页/表头/占位/字形/页码），不是**金融内容正确性**：
  数字能否回溯到底稿与来源，属 S1 的单独关卡。
- 样例是合成的固定夹具（`scripts/pdf_visual_check.py` 内），不代表真实任务报告的全部形态。
