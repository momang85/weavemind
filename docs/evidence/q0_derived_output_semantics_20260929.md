## 2. 顺带查出的**位置错位**缺陷（比上面两条影响更大）

`acceptance_checker.extract_financial_numbers()` 旧实现先**改写文本**再记位置：

```python
t = re.sub(r"!\[[^\]]*\]\([^)]*\)", " ", t)   # 图片 → 一个空格（字符串变短）
t = re.sub(r"[A-Za-z]:\\[^\s]*", " ", t)      # C:\… → 一个空格
t = re.sub(r"/tasks/ui-[a-z0-9]+/[^\s]*", " ", t)
... "pos": m.start()      # ← 相对**被改写过的**文本
```

而所有消费 `pos` 的地方（`_match_derived_fact` 取数字**所在子句**、主体归属、`_promotion_key`
提升键、`metadata_numbers`）拿的是**原报告** → 每个 `pos` 都往前错位，读到的是**邻句**。
冻结样本 `ui-a06a005c9b` 实测（改前）：

```
15.01亿元  报 pos=18540 → 原报告 body[18540:18547] = '-33.43'   （真实位置 9346）
42.50 亿元 报 pos=8635  → 原报告该处是 '……项目合计对……'        （真实位置 8734）
```

后果有两个方向：**假通过**（真的跨公司/跨指标数字因为读到邻句而放行，护栏形同虚设）
与**假失败**（诚实的派生读数被邻句的主体否定）。修法：不再改写文本，改为**记录区间并跳过**
（`skip_spans`），`pos` 始终索引调用方给的那份原文；`metadata_numbers` 同口径。改后
`extract_financial_numbers` 的 375 个数字**逐个**满足 `report[pos:pos+len(raw)] == raw`
（改前错位 ≥ 200 处）；用例 `test_number_positions_index_the_report_text` 守住。

## 5. 代码改动清单

- `acceptance_checker.py`
  - 新增 `_divisor_constants()`（算式里**除号右侧**的字面量）、`_years_of()`、
    `_RATIO_METRIC_INPUTS`/`_COMPOSITE_DERIVED_METRICS`（与产出侧一一对应的规则表）、
    `_derived_output_contract()`：主体/币种/口径**原样继承**（输入未标则输出不得自称）、
    单位/量纲由**算式形状**决定（百分比需有除法；金额需同量纲且不得对输入做除法）、
    期间年份必须落在输入年份内、指标必须由 `_yoy`/`_change`/比率注册表/复合派生/同名
    再表达之一决定，且 `_yoy` 的分母必须是**基期**那一项。
  - `_verify_derived_row()` 增加第 5 关（输出侧契约），前 4 关一字未改。
  - 新增 `_INDICATOR_KEY_GROUPS`/`_METRIC_KEY_BY_SLUG`/`_body_indicator_key()`/
    `_fact_metric_key()`/`_derived_body_semantics()`：正文数字的**指标/期间**必须与
    派生事实相容（两侧都取到才判，任一侧未知不据此否决）。
  - `_match_derived_fact()` 增加第 4 条（指标/期间），并改用 `_clause_span` 求数字在子句内的偏移。
  - `extract_financial_numbers()`/`metadata_numbers()`：**不改写文本**，改记区间跳过，
    位置索引回原文（§2）。
- `test_p0.py`：+5 用例（伪造元数据被拒且逐字段验；真形状七类通过 + 规则表一致性；
  分母必须是基期；正文跨指标/跨期间不得借用；位置必须索引原文）。
- `scripts/q0_traceability_replay.py`（新）：对冻结任务**只读**复算溯源读数，
  任何人可用同一命令复现上表（不再把这类脚本只留在临时目录）。
