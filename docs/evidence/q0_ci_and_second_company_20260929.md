## 1. CI 状态：按可核对的事实更正

架构师指出：状态文件多段旧"C/D 未做""只剩环境项"，且不得把"仓库没有 CI"写成事实。实测：

|---|---|---|
| 配置在不在 | `.github/workflows/ci.yml` **已存在且被跟踪** | `git ls-files .github/workflows/ci.yml` |
| 覆盖是否完整 | 48 个 `run: python test_*.py` == 48 个已跟踪 `test_*.py` | 步骤计数与 `git ls-files "test_*.py"` 双向比对 |
| 本地守卫 | `python test_deploy_manifest.py` → **39 OK**（含"每个测试文件都要在 CI 里"那条） | 本机逐文件跑 |
| 远端最近一次 | 最后**已推送**提交 `2519d9a` 上 CI = **failure**：唯一失败步骤 `backend / Deploy manifest & lock guards`，原因 `test_question_assessment.py` 不在 CI 内（日志 `AssertionError: Lists differ: ['test_question_assessment.py'] != []`） | `gh run list --workflow CI` + `gh run view 36309205043 --json jobs/--log-failed`（只读） |

结论口径：**"CI 已配置、本地守卫通过、远端结果只到 `2519d9a` 且为 fail、当前树无远端记录"**；
不是"仓库没配 CI"，也不是"CI 通过"。按纪律**不推送**（未授权），因此本批远端结论保持"无记录"。

## 2. 第二家公司真实资料：四条正常入口的实测结果

目标：把**另一家非金融 A 股公司**的真实披露通过**正常入口**（应用自己的适配器/检索通道，
确定性、不调模型、不新增付费服务）取进来，并给出主体/期间/披露日/覆盖。
本轮选 `三一重工 600031.SH`（机械制造，与已有一家白酒的经营特点不同）。

| 入口 | 实测 | 结论 |
|---|---|---|
| ① 巨潮公告发现（`disclosure_ingest.discover`） | 返回 `status=unavailable`，原因"巨潮公告发现接口未连通（探针恒空/需 token），本版本不做自动发现"，并给出 `next_steps`（官方直链 / 人工取得文件） | **按设计未连通**：这是骨架，不是"全接通"；不绕验证码、不伪造 token |
| ② Bing HTML 检索（`text_search._search_bing`，3 个查询，各 1 次有界请求） | 每个查询返回 8 条，**全部**是公司官网/百科（`sanygroup.com`/`sanyglobal.com`/`baike.baidu.com`）；`pick_official_candidates(...period="2024")` **0 条** | 该通道对本查询**没有官方披露候选**（站内 PDF 未被 surfacing） |
| ③ DDGS（`web_text_search`，单后端 `brave`，2 个查询） | 均 **0 条**（且无异常，`_search_ddg` 直调也是 0 条） | 该后端在本环境返回空 |
| ④ 东财结构化（`eastmoney.fetch_ashare`） | 报错；进一步用**原始 URL** 直取：两个报表 `RPT_MAINFINADATA`/`RPT_F10_A` 对 `002304.SZ`（已知曾有数据）与 `600031.SH` **都返回 77 字节空载荷 / rows=0** | **站点/出口侧限制**（对照组同样为空），不是代码格式问题 |

**因此本轮没有取得第二家公司的真实原文**——如实记录，不用第一家的材料冒充、不手拼 URL
（手拼直链会绕过"不新建请求点"的纪律）、不绕访问保护。可用的两条正常补料方式（应用已支持）：

1. **官方直链**（`manual_url`）：在官方披露平台打开该年报 → 复制 PDF 直链 → 走应用的材料入口
   （`POST /api/task/<id>/material` 或页面「补材料」），准入按结构化报告期/类型/披露截止判定；
   上一家公司真实链就是这么打通的（镜像站直链被正确拒收 → 换巨潮官方直链后 `admitted`）。
2. **人工取得的文件**（`manual_file`）：把 PDF 放进材料入口，走同一条摄取与准入。

时机限制说明：②③④ 都是**对外部站点的实时可用性**依赖，本环境当前不可用；
取得直链后，摄取→准入→并入→候选正文→同版导出这条链与洋河样本完全同源，不需要新代码。
