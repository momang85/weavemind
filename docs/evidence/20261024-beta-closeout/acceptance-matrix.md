## 4. 下一步建议（按影响排序）

1. **常见条件与行情/财务数据覆盖**：现在只有 5 个财务字段白名单 + 内置缓存 2 家；下一批先把「常见筛选条件」（连续增长、行业对比、估值/行情）与财务数据的真实覆盖做出来，再谈复杂因子。
2. **自然语言条件接缝（NL-condition seam）**：把「自然语言 → 规则 JSON」做成显式、可回显、可拒绝的接缝（模型只产候选规则，落库前必须由用户确认），避免把「模型理解」混进机器验收。
3. **历史实验缺口**：运行可按 run_id 重放，但缺「同一规则集跨时间跑」的对照视图；建议补「规则集版本 + 期间片段」的实验台账。
4. **小团队共享权限**：当前作用域是「用户/项目」，数据集不可跨账户；团队共享需要显式的共享对象 + 审计，不建议直接放宽为全局可见。
5. **文件与下载环境**：把「原生文件选择 / 下载落盘」写成安装自检项（扩展权限 + 下载目录），避免每次验收都卡在环境。
6. **本机 Python 版本**：CI 与试用包应锁定 3.11；本机需补装 3.11 才能完成 C3-7。
