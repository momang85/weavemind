# C2 人工复核清单（5 分钟，浏览器 DevTools）

> 本单环境无法完成的项目，按此清单可在任意 Chrome/Edge 上复核；每项都给出预期结果。

1. **原生文件选择器上传**
   - 前置：`chrome://extensions` → Kimi → 详情 → 打开「允许访问文件网址」。
   - 步骤：「可解释选股」→ 数据准备 → 「上传 CSV 数据」→ 选 `tmp/c2-upload.csv`（表头 `entity,code,period,revenue,gross_profit,total_assets,total_liabilities`）。
   - 预期：数据集出现在「数据来源」下拉，标签「我上传：c2-upload.csv」，`official=false / user_provided=true`；运行结果顶部提示「本次结果包含用户提供的数据…未独立核验」。

2. **下载模板落盘**
   - 步骤：点「下载模板（CSV）」→ 看 Chrome 下载气泡与 `下载` 目录。
   - 预期：文件落盘，首行为 `entity,code,period,unit,currency,caliber,period_type,source_url,available_at,…`；若仍不落盘，检查 `chrome://settings/downloads` 与安全软件。

3. **跨账号模板导入**
   - 步骤：A 账号（researcher）导出规则模板 JSON → B 账号（momang）导入。
   - 预期：B 的规则条数与字段和 A 完全一致；只带规则，不带任何行数据或作用域数据。

4. **未保存表单保留**
   - 步骤：填 3 条规则 + 期间 2024，点「预览输入」再点「执行筛选」。
   - 预期：规则与期间不被清空；失败提示出现时输入仍在。

5. **超时与重试**
   - 步骤：断网或限速后点「整批取数并生成数据集」。
   - 预期：300s 内给出超时/失败提示，不生成半成品数据集；重试后成功且不产生重复数据集（内容定址复用同一 id）。

6. **乱序响应 / 双标签**
   - 步骤：两个标签都打开「可解释选股」；A 加清单某代码，B 同时加另一个代码；A 再删一个被 B 改过的条目。
   - 预期：后写方收到 409「已被其他窗口修改」，页面提示刷新后重试，不静默丢更新。

7. **后台恢复**
   - 步骤：切到其他标签 2 分钟后回来，切换数据来源、改规则、再回来。
   - 预期：页面状态与来源选择保持；手动刷新后：运行历史、数据集、清单仍在（服务端权威）。

8. **390 / 420 px 窄屏**
   - 步骤：DevTools 设备模式 390×844、420×900。
   - 预期：无横向滚动；表格可横向滚动但列头可读；按钮不重叠；Tab 键焦点可见（有 focus ring）。

9. **清单 200 条**
   - 步骤：批量加入至 200 条（可用 API：`POST /api/screen/watchlist {action:add}`）。
   - 预期：清单显示 200 条、`integrity=ok`；筛选「只看」与排序在此规模下不卡顿；重复代码不重复入列。
