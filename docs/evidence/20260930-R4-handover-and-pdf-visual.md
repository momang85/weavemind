## 2. 残差（不掩饰，也不夸大）

1. **利润—现金仍是"总额观察"**：算子给的是 `Δ(经营现金流 − 归母净利)` 与覆盖率，
   **没有**现金流量表调节明细（折旧摊销/营运资本变动/减值/税项逐项）。缺的是原始附注；
   证据里不得写成"已取得现金流调节明细"。
2. **毛利线以下一段仍待证**：`profit_bridge`/`profit_to_cash` 都把它标为"未解释段"
   （含费用/税项/投资收益/少数股东），需要利润表明细才能拆。
3. **计划层可答 ≠ 执行层已答**：京蓝的情景在计划里"已回答"，运行时如实 `not_applicable`。
   卡片/正文按**实际运行状态**展示（`not_applicable` 不出卡），因此交付层是诚实的；
   这条提醒读者：计划是意图，结论以运行为准。
4. **量价/分部结构**：仍无注册模型（问题类型里有缺口说明），需要年报"经营情况讨论与分析"。
5. **下一功能（R4 之后）**：只补与问题有关的**原始附注/费用税项/营运资本调节**，复用现有四族；
   本批**未新增**算子。
