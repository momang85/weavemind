## 4. 复用的边界（U90-B.3 的诚实结论）

- **真实运行可验的部分**：崩溃任务的终态可人工恢复；工作区产物不被清理、结构化财务载荷被复用；
  未完成的步骤才重跑；重复恢复被 409 拒绝；一次恢复只产生一个新尝试/一次出包。
- **真实运行验不到的部分**：`跳过 N/M 个已完成步骤` 的复用，本批**没有可用的真实样本**——
  所有含 SUCCESS 步骤的历史失败任务（如 `ui-ffd3ddcf5a` 7/11 步 SUCCESS、`ui-fa2cb73e59` 多步 SUCCESS）
  工作区目录都已被清理，产物无从谈起，恢复即全量重跑。故"有效断点复用"的证据来自
  **隔离演练**（`recovery_drill.md|json`：真 `task_state` + 真 `_execute_steps(resume_completed=True)`，
  只桩掉真正花钱的 `_dispatch_step_safe`；跳过 2/5 步、删工作区后复用数 0）。
  **真实运行中的跳过复用 = 未验**，如实单列，不拿组件级证据冒充实机证据。
