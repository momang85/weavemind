## K3：页面「改假设 → 复算 → 采纳 → 导出」（`e7deafe`）

- **接口**：`GET /analysis`（可用模型 + 允许改的假设与范围 + 运行/输出/公式/限制 + 输入 + 当前包）、
  `POST /analysis/recompute`（确定性复算：新 run、旧 run 保留、`adopted:false`、参数越界 400、
  不适用如实 200+说明且不落盘）、`POST /analysis/adopt`（只收**已验证** run；走同一条

- **页面**：新增 `AnalysisWorkbenchPanel`（挂进 ReportViewer）：分析卡 → 假设输入（显示声明范围）
  → 确定性复算 → 前后对比表 → 采纳这版 → **导出当前包**（用 `current_package`，不取最新 zip）。
- **顺手修掉两处"改了不生效"的真缺陷**（一上手就撞到）：
  ① `scenario_sensitivity` 声明 `revenue_growth/gross_margin_delta/expense_change_ratio`，
  compute/gold 却只读旧名 `up_*` → 页面按声明改假设改了不生效；现由 `_assumptions()` 统一解析
  （声明名优先、旧名兼容，compute 与 gold **共用**）。
