## 1. 打开方式

- 你自己的实例：登录后侧栏「筛选」→ 结果行「看公司」；清单条目「看公司」；「查看变化（相对上次记录）」。

## 2. 必看（5 分钟）

1. **三入口同一页**：结果行（带 run）、清单条目（只带代码 → 先让你选记录）、数据集（只读，明示不执行筛选）。确认没有「输入代码就自动打开一份不明来源记录」。
2. **首屏四问**：哪家公司 / 哪份数据 / 数据到哪天 / 能看什么。来源标签是否与实际材料一致（官方缓存 / 我上传 / 研究材料 / 合成演示）。
3. **条件表**：每条读数的状态（命中/未命中/资料不足/不可算/待核验）与原因是否说得通；缺口、冲突、待核验是否单独列出，而不是被一个「通过」盖掉。
4. **变化简报**：选两份记录 → 生成。确认标题是「本次记录相对上次记录」，不是自动日报；逐家卡片里「旧值→新值、差额、相对变化、证据链接」能点回原始记录；没有变化的公司明确写「未观察到变化」。
5. **不可比提示**：若两份记录的规则/期间政策/来源不同，是否出现「条件不同/不可比，读数差异不能当成经营变化」。
6. **基准**：看简报本身**不应**改变跟踪基准；只有点「设为跟踪基准」才改；两个标签页同时改时应有一个拿到「版本冲突，请刷新」而不是静默覆盖。
