# 10-07 判断随数据（方向／可用性／原句）— 实现与验证

基线 `4cbea3b` ＋ [10-07 复核](20261007-results-review/review.md)。本批主任务：
**让金融判断随当次读数的符号、可用性与真实原句变化**，而不是换标题词；并用
**最终 reader 对象与最终正文**核验（不只核对照表）。

## 一、改了什么（都在既有对象/接缝里，不新增规则 DSL、不硬编码公司）

| 位置 | 改前（复核点名的反例） | 改后 |
|---|---|---|
| `judgments.py` 利润机制 | 标题写死「利润**下降**的主因在毛利端，**税费减少托底**」 | 由 `Δ归母净利润` 的符号与各分项**贡献符号**生成：利润改善↔下降、税费缓冲↔拖累↔推动↔加重下降；分项标明是**对利润变化的贡献**（所得税费用上升＝负贡献） |
| `judgments.py` 税费假说与下一观察 | 写死「税费减少是不是可持续」 | 随方向给：拖累时问「税费增加是不是结构性/一次性」，支持/削弱条件一并随方向 |
| `_merge_volume_price` | 量价**全缺**时仍写死「**销量收缩**是数量观察…」并标**已发生（读数）** | 缺哪项写缺哪项；全缺 `kind=gap`（新标签「读数不足（不作结论）」），并**排到强结论之后**（保留缺口、不占席位） |
| 现金判断 | 借词写死「营运资本净**缓冲**主要来自应付项目（**占用未随采购同步下降**）」 | 标题随 `ΔOCF` 方向（下降/改善×主导/推动）；三行（应付/存货/应收）**逐项给方向**；只陈述**会计构成**，商业原因明确标**未证**，发行人原句若有则原样引用 |
| 结构判断 | 写死「**降幅差**说明结构在起作用」 | 按分段数值符号取「降幅差／增幅差／增减差」 |
| 情景边界 | 写死「要**回到**目标利润水平」 | 按门槛与基期的距离方向：已高出门槛时写「基期毛利率已高出所需门槛 X pp（单因素条件计算）」 |
| 目标兑现 | 草稿把**计划句自己**当实际完成（仅「公司计划营业收入同比增长5%」⇒ actual=5%、宣告兑现），并硬写酒类原因 | 重做为**两份证据、一条命题**：计划与实际各自有**原句＋定位＋发布时点＋所指年度**；同主体、同年度才比较；**只有计划即未知**（`kind=gap`）；发行人原因**只取真实原句** |
| `report_brief._admitted_records` | 丢掉 `published_at`/`subject` | 透传（目标兑现要「发布时点/主体」） |

## 二、四类最小函数验证（真实读数 → 最终 reader 对象）

用**真实运行数据**跑生产函数（`report_brief._analysis_context` → `research_judgments`
→ `select_reader_judgments` → `render_reader_judgments`），下面是选出的**读者判断**原文。

**洋河（下降年，真实任务工作区 `ui-10ea37599d`，5 条）**

1. 经营计划（2024 年，营业收入同比 +5%~+10%）**未兑现**：全年 -12.83%，低于计划下限 17.83pp（低于上限 22.83pp）｜披露时点 2025-04-29
2. **利润下降**的主因在毛利端（-38.01亿元），税费是**缓冲**（未改变下降方向） +11.64亿元
3. 收入变化的量与价：**销量收缩**是数量观察；**单位收入上升不证明提价**；成品库存积累使「销量恢复与库存消化」成为优先观察
4. **现金下降**由利润变化主导，营运资本是缓冲/拖累——缓冲能不能持续才是关键
5. 要回到目标利润水平：毛利率需再高 11.58pp（或收入按单因素变化）——条件计算

**三一（增长年，离线生产链 `rep-sany-1007`，5 条）**

1. **利润改善**的主因在毛利端（+13.86亿元），税费是**拖累** -1.12亿元
2. **现金改善**主要由营运资本（占用与时点）**推动**，其持续性是关键
3. 按目标利润水平反推：基期毛利率已高出所需门槛 1.86pp（单因素条件计算，不表示可达）
4. 产品/区域结构是**同一个口径的不同切法**：**增减差**说明结构在起作用
5. 收入变化的量与价：销量效应**未取到**，不生成数量结论；单位收入效应**未取到**，不评价价格 ｜**读数不足（不作结论）**

**量价全缺**：合并条不再出现「销量收缩」，标 `读数不足（不作结论）`，且排在强结论之后
（`TestReaderJudgmentSelection.test_all_gap_volume_price_is_not_an_observed_conclusion`）。

**仅计划**：`plan_target_of()` 返回 `actual=None` ⇒ 标题「…**兑现未知**：未取得同年度独立实际读数」，
`kind=gap`，**不**出现「达到或超过计划上限」，**不**编发行人原因
（`TestTargetFulfilmentTwoEvidence`）。反例输入＝复核给的
「公司计划营业收入同比增长5%，努力实现稳定经营。」。

三一改后证据：[20261007-sany-direction.json](20261007-sany-direction.json)（`wrong_direction_markers`
四项全 `false`）；10-06 的错误正文留在 [20261006-sany-replication](20261006-sany-replication/report.md)
作对照，两份都未删。

## 三、随样品只补的三个接缝（各带反例与守卫）

1. **缺 `available_at` 也不得越过评价日**（`quant_research/event_returns.py`）：此前只有显式声明
   `available_at` 的行才设门槛 ⇒ 删掉该字段后，评价日 2025-01-02 仍把 01-03/01-06 判 `observed`
   （有无日历都一样）。现在**日期自身**也必须 ≤ 评价日；不过 ⇒ `pending`（不是 `missing`）。
   守卫：`test_market_events.TimeContractTest.test_missing_available_at_still_cannot_cross_the_evaluation_date`。
2. **坏/未知量化成员阻止量化外发**（`quant_research/publish.py`）：此前 `_unreadable`（下划线键）
   被许可门跳过 ⇒「授权 `event_returns` ＋ 坏 `backtest.json`」判 `allowed=true`、坏文件照旧随包。
   现在坏成员与未登记成员一律 **fail-closed**（判不出许可＝不放行）；内部快照保留、财报正文照常。
   守卫：`test_quant_publish`（含**授权＋坏文件**的组合反例与投影反例）。
3. **替代步骤有 ID 但 FAILED／未知不算恢复**（`delivery_pipeline._replacement_recovered`）：此前只看
   `replacement_step_id` 是否存在。现在只有 `replacement_outcome` 明确成功才解除报告失败门。
   守卫：`test_r0_boundaries.TestResearchHardGate`（`FAILED`／空／`PENDING` 三种都判失败门）。
