## 1. 定向取证（F2-1）

**新增 `narrative_evidence.py`**（确定性、无 LLM）：按小节标题切分抓取正文 → 关键词归类
（业务背景/经营变化解释/财务附注/风险因素）→ 每条留 400 字短证据 + **小节路径 + 字符区间**。

四类命中读数（离线夹具 `ANNUAL_TEXT`，`periods=[2023,2024]`）：

```
business_background | 第三节 管理层讨论与分析 > （一）主营业务情况（字符 14-86）
change_explanation  | 第三节 管理层讨论与分析 > 一、经营情况讨论与分析（字符 29-302）
footnote            | 第三节 管理层讨论与分析 > 七、财务报表附注（字符 141-314）
risk                | 第三节 管理层讨论与分析 > 二、可能面对的风险（字符 86-141）
missing_kinds = []          # 四类都取得了带定位的证据
```

- **只定位、不编造**：没抓到的类别进 `missing_kinds`，报告必须写"需核查"，不得用模型知识补原因。
- **检索摘要不算证据**：`search_results.json` 只有 snippet、没有正文 → `has_location=False`，
  不计入"已取得证据"（`test_search_snippet_alone_is_not_evidence`）。
- **定位口径诚实**：网页没有页码 → 记"小节 + 字符区间"，附录写明"年报 PDF 的页码待后续支持"。
- **跨页保留**：每次抓取成功都会重跑本函数，同 URL 以本轮重新抽取为准，其余页面的证据**保留**
  （抓取回灌写快照有 300 字门槛，不能假定快照一定收录了每一页）。

**研究路径接线**（`orchestrator_v2.py`）：

| 步骤 | 变化 |
|---|---|
| 1 搜索 | 指令要求"至少一条指向契约期间的**发行人年报/公告**（经营情况讨论与分析、财务附注、风险因素）" |
| 2 抓取 | 改为抓**年报正文页**（数字仍来自结构化适配器），要求保留小节标题 |
| **2b 抓取（新增）** | 抓与步骤 2 **不同**的一页（附注/风险/数据）；`optional=True` |
| 3/4 | 注入新增的 `[已取证据]` 块（≤6 条、每条 ≤300 字、带小节定位） |

- **有界**：不新增搜索步骤、不循环；第二个来源取不到**不算任务失败**（`optional` 依赖失败不阻塞
  下游，也不进打包依赖），缺口照实记。
- **角色分流**：`_pick_fetch_url(role=…)` 按 `step_id` 分流（`2`→年报正文、`2b`→附注/风险），
  并排除已抓取 URL；**角色步骤不追加兜底 URL**，没有候选时 worker 直接返回
  `{"status":"failed","error":"No URL found in instruction"}`（不联网、不抓重）。
  读数：同一份候选列表下 `role="annual_report"` → 年报页，`role="notes"` → 附注风险页，两者不同；
  排除全部候选时返回 `None`。

### 1.1 顺带修掉的两个真缺陷（离线关卡暴露）

1. **离线替身的 `web_fetch` 回包缺 `status` 字段**。`tool_contracts` 要求 `status`，缺了会被判
   契约不符 → 触发重试与**单步重规划**，抓取结果被换成别的步骤的输出（搜索文本）。
   读数（修前）：`DISPATCH: 2 web_fetch -> SUCCESS | 搜索结果：…`、`POP key=task_result:alt-2-…`。
   这意味着 C 批的离线研究路径**从未真正跑通抓取回包形态**。修：替身补 `status: success` 并加长
   正文（≥300 字，走真实的快照回灌路径）。
2. **工程收尾报告被当成"分析"**。正文模型失败时 `_finalize` 的 `## Task Report / Steps: 5 (4 OK,
   1 failed)` 会成为"正文"，`report_brief._analysis_section` 原来照单收下 → 简报的 `## 分析` 一节
   是步骤成功数，交付仍判 `verified`。修：`_analysis_section` 识别工程报告形态并返回空；交付硬门槛
   新增"分析未完成"判据（`delivery_pipeline._has_analysis_section`）。
   读数（修后）：`gate hard_fail=分析未完成：交付正文只有数据与底稿…`、`status=draft`。
