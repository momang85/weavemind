1. `browser_open http://127.0.0.1:8080/` → 登录（`momang`）；

## 二、看图看到的三处缺陷（都不是"接口返回错"，接口全是对的）

| # | 看到的现象 | 判定 | 修法 |
|---|---|---|---|
| 1 | 补材料面板里 `**已并入**`、`**不采纳**`、`**同一准入判据**` 等**字面星号**直接显示 | JSX 文本节点里写的是 Markdown 强调语法，React 不解析 → 读者看到一串星号 | 去掉星号，需要强调处用 `<span className="text-slate-400">` |
| 2 | 首屏「**结论速览**」四格里是 **白酒销售量 139,076.05 / 生产量 145,494.73 / 库存量 45,594.72** | 卡片取"正文第一张表"，而该简报的第一张表是**实物量（吨）表**——**卡片名与内容不符**（数字没错、标题说谎），同一族问题 | 取表改为**优先表头含"指标"的表**（=财务对照）；退回首表时标题改成「正文首表前 4 行」并注明"未判定为结论"；无表降级的卡片标题从"结论速览"改为「验收器统计」 |
| 3 | 简报面板研究状态行写着 `本条说的是**研究**是否就绪`；导出块写着 `按**当前版本**导出` | 同上（字面星号） | 去星号 + 用 span 强调 |

**关键点**：这三处**单测与接口断言都抓不到**——`/api/task/<id>` 返回的正文是正确 Markdown
（`**` 在那里本来就该有），错的是**渲染层**。只有看图才看得见。

## 三、修后（同一页面、重新构建 dist 后复看）

- 数据卡标题 **「关键数据速览」**，副标题「取自报告正文『财务对照』表前 4 行（指标 × 期间 × 口径 × 来源）」，
  四格为 **营业收入 331.26亿元 / 归母净利润 100.16亿元 / 经营活动现金流净额 61.3亿元 / 毛利润 249.26亿元**；
- 研究状态行：`本条说的是研究是否就绪，不改变数字与格式的机器验收结论`（无星号）；
- 导出块：`Markdown / PDF 按当前版本导出（响应头带版本号）`（无星号）；
- 补材料面板：新增的「按新材料生成候选正文」区块正常渲染（图标 + 说明 + 按钮 + 前置条件提示）。

`frontend/dist` 已重建（`tsc -b` 0 错、`vite build` 成功）；`web_ui.DIST_DIR` 指向
`frontend/dist`，**刷新页面即生效，无需重启服务**（已实测：改前改后同一 URL）。
