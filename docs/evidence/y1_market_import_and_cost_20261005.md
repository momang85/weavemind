## 一、导入契约（`market_history/0`，候选位置 `adapters/market_history.py`，本轮未实现）

```json
{"schema": "weavemind.market_history/0",
 "dataset_id": "<sha256(文件字节)>", "source": "<供应商/授权凭证名>", "license": "<个人非商业|机构授权|未知>",
 "imported_at": "<采集时间>", "as_of": null,
 "instruments": [{"code": "002304.SZ", "role": "subject"},
                 {"code": "600031.SH", "role": "subject"},
                 {"code": "<基准代码>", "role": "benchmark"}],
 "calendar": {"exchange": "SZSE|SSE", "file": "<交易日历文件或停牌口径说明>"},
 "rows": [{"code": "002304.SZ", "date": "2025-04-29", "open": null, "high": null, "low": null,
           "close": null, "volume": null, "adj_factor": null, "available_at": "2025-04-29T15:00:00+08:00",
           "source": "<文件>"}],
 "unavailable": [{"what": "rows", "reason": "本机无授权历史行情文件；不安装采购引擎、不猜最新 CSV、不用快照拼历史"}]}
```

**字段校验（导入即拒，不猜）**：`code` 必须能解析为 `entity_id`；`date` 必须是交易日；`available_at` 必填
（防未来函数：**事件日之后才可用的行不得参与该事件的收益窗口**）；`adj_factor` 缺失时只报**未复权**并标注；
`role=benchmark` 缺失时只报绝对收益并标注"无基准"；`license` 为"个人非商业"时**不得**进入对外下载包
（Tushare 协议二(二)5；银行/收费用途须另行授权）。

**事件收益观察的最小窗口**（Y2a，需真实行情才做）：事件日 `t0`（用**当时**披露日，日精度即可）、
窗口 `t0+1/+5/+20` 交易日、基准同窗口、重叠事件去重、退市/停牌缺失处理口径写明；
**样本不足只交描述结果，不声称 alpha/因果**。
