# 门禁（Mimosa 钩子）处理记录

本文件记录**每一次**被门禁拦下的命中详情、判断依据与恢复证据。目的：把"临时移开钩子"
限定为当次、有据可查的例外，而不是可以反复援引的通用授权。

处理原则：先看命中内容 → 判断是否与本次改动相关 → 相关就改代码/改提交内容；
确认是**既有代码的误报**且本次不修那部分时，才临时移开钩子完成提交，**提交后立即恢复**，
并把命中清单与恢复证据写进本文件。

## 2026-09-14 · Bash 调用拦截（PreToolUse，写源码判定）

- **规则**：Mimosa 拒绝"通过 Bash 直接写源码/安全配置"，要求改用 Write/Edit/MultiEdit。
- **命中命令与文件**：
  1. `python -m py_compile <file>.py`（被判定为写源码）——改用语法的间接校验（测试导入）绕过；
  2. `cp metrics_collector.py <目标目录>/`（把后端改动同步到本地模拟实例）——改为只同步
     `frontend/dist` 等非源码产物，后端改动由单元测试覆盖；
  3. `cat > <脚本>.py <<EOF`（一次性迁移脚本）——改为逐文件 Edit。
- **判断**：**不是误报**，是门禁在阻止"绕过 Write/Edit 审查直接落源码"，属于设计内行为。
  本次遵守该约束：所有源码改动均通过 Write/Edit 提交，未用 Bash 写任何 `.py`。
- **动作**：无移开/恢复操作（该规则不涉及钩子文件），仅记录以说明上列的规避路径。
