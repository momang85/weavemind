### 本轮实机暴露并已修的缺陷（都带对应离线回归）

1. **取消无法打断"模型调用/探测"的等待**：端点退化（504/读超时）时，规划调用或健康/余额探测
   会把"停止"推迟到调用自己失败为止（实测 3600s、58s）。
   修：`_call_llm_cancellable` 把模型调用放到工作线程、主线程按 1 秒分片轮询取消，
   命中即放弃等待并抛 `TaskCancelled` 走取消收尾；健康预检、余额预检、规划调用都走它。
   回归：`test_cancel_semantics.TestCancellableLlmWait`。
2. **预算耗尽只拒绝单次派发**：重试/重做循环每 2 秒再试一次，任务永远收不了尾。
   修：派发被拒时置运行级标记，`_dispatch_step_safe` 不再重试、`_execute_steps` 停止派发剩余步骤、
   迭代循环停止进入新一轮，收尾在交付物上写明"因预算耗尽提前收尾"。
   回归：`test_root_budget.TestBudgetExhaustionStopsRun`。
3. **配置里的预算上限不生效**：加载器 `llm_client._load_config` 不存在 → 静默回落到 `task_timeout`。
   修：改用编排器自己的配置路径（与 system 段热重载同源）。
   回归：`test_root_budget.TestBudgetLimitsFromRealConfigPath`。
4. **研究类任务从不产生验收**：验收只在 `report_generator` 步骤后触发，而研究任务常被规划成
   单个 `content_summary` → 交付恒被判"未验收草稿"。
   修：计划里没有独立报告步骤时，最后一步 `content_summary` 的输出也按同一正文过验收。
   回归：`test_offline_delivery`（离线完整交付用 content_summary 路径覆盖）。
5. **快速路径/单步任务没有选中版本**：验收 pass 却被判草稿（实机第 3 次）。
   修：收尾时若尚无选中版本，按研究正文补齐"登记 + 采纳"。
6. **未验收草稿只在日志里说**：现在写进交付物本体（页面/导出可见），且状态如实降级为
   `SUCCESS_WITH_ISSUES`（`task_state.derive_status` 新增 `draft_delivery` 入参）。

### 未验证 / 已知缺口（本轮不做假结论）

- **UI 鉴权与页面渲染未验证**：本机当前无有效会话，`session:*` 为空，我没有凭据、也没有新建
  旁路凭据；任务提交走的是 webui 同一条内部通道（`orchestrator:main` + `task_ack`），
  页面/前端只核对了"任务投影与交付产物"的数据一致性，没有走浏览器。
- 模型端点本轮持续不稳定（504/读超时/推理预算耗尽），**happy path 只在第 4 次跑到**
  （验收 pass + 交付非草稿）；其余次数是端点退化下的降级路径，未据此宣称"稳定"。
- Embedding 仍欠费（siliconflow 402）：对话写入排队待补录（既有行为），
  策略沉淀本轮没有发生（准入拒绝，属正确行为）。
- 取消延迟 13s 主要来自 1 秒分片轮询 +（可能）一次在飞调用的收尾开销；
  "≤3s" 级别需要把取消信号进一步传进 `llm_client` 的每次重试间隙（未做）。
- 应用内定时任务（scheduler）与本次实跑并发争用同一端点，观测到的耗时包含这部分干扰。

## 本轮暴露、交由后续批次修的缺陷

1. **票据账不平（R2）**：任务③账本是"真实 `plan-1` 已结算 + 虚构 `规划-inflight` 未结算"，
   `1/1/1` 是假平衡；且未写 `inflight_unsettled.json`。取消后的在飞对账没有真票据。
2. **0 值语义（R2）**：配置 0（不限）实际回落 `task_timeout=600s`，任务①即因此被提前收尾。
3. **目标达成判定（R0.1）**：任务①②都 FAILED，但命中的判定理由不同（① 靠 financial 严格档，
   ② 根本没跑到验收）；"零数字/无来源更易通过"的组合漏洞仍待 R0.1 处理。
4. **版本身份与交付谓词（R0.2/R0.3）**：任务①验收已算出 `fail`（sha `f19808be…`），
   但交付判定仍是"该版本没有对应它自身的验收（未知）"——"绑定验收 ≠ 通过验收"的真实表现。
5. **检索通道质量**：`web_search` 对茅台类查询返回无关结果（手机市场份额），
   是本轮两个任务失败的直接原因；属外部依赖质量，记入 M1 前要处理的前置问题。
6. **PDF 体积**：5.2KB 报告生成 5.3MB PDF（字体嵌入未子集化），记入 B 批。
